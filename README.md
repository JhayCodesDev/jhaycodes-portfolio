# JhayCodes — Developer Portfolio

A personal developer portfolio built to showcase my projects, technical skills, learning journey, and the things I'm currently building.

The portfolio reflects how I approach development: **build, learn, understand, and improve.**

## 🚀 About

I'm a frontend and software developer interested in building practical digital experiences while understanding the technology behind them.

This portfolio serves as a central place to showcase my work, skills, experience, and ongoing journey as a developer.

## ✨ Features

* Responsive design across different screen sizes
* Dark and light theme support
* Interactive navigation
* Mobile navigation menu
* Smooth scrolling
* Dedicated work/projects page
* Custom 404 Not Found page
* Interactive hero visual
* Responsive project layouts
* Accessible navigation and interactive elements

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/JhayCodesDev/jhaycodes-portfolio
```

### 2. Navigate into the project

```bash
cd jhaycodes-porfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will then be available through the local development URL provided by Vite.

## 📦 Production Build

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🌐 Deployment

The portfolio is intended to be deployed using Vercel.

The deployment process uses the project's GitHub repository and automatically builds the application using the configured Vite setup.
